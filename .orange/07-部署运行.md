# 07 部署与运行

## 快速开始

### 方式一：本地开发（推荐入门）

```bash
# 1. 安装依赖（需要 Node 22+、pnpm、uv、nginx）
make check    # 检查依赖是否满足
make setup    # 交互式向导（配置 LLM、生成 config.yaml）
make install  # 安装前后端依赖

# 2. 启动
make dev      # 启动所有服务（Gateway + Frontend + Nginx）

# 3. 停止
make stop
```

访问地址：`http://localhost:2026`

### 方式二：Docker（推荐生产）

```bash
# 初始化（仅首次，拉取 sandbox 镜像）
make docker-init

# 开发模式（热重载，源码挂载）
make docker-start

# 生产模式（本地构建镜像）
make up

# 停止
make down
```

## 配置文件体系

### 主配置文件 `config.yaml`

从 `config.example.yaml` 复制，核心配置段：

```yaml
# LLM 模型配置（支持多个）
models:
  - name: "default"
    provider: "openai"           # 或 anthropic / google / deepseek / ...
    class: "ChatOpenAI"          # LangChain Provider 类路径
    api_key: "${OPENAI_API_KEY}"
    model_name: "gpt-4o"
    vision: true                 # 是否支持图像输入
    thinking: false              # 是否支持思维链

# 工具配置
tools:
  - name: "web_search"
    type: "duckduckgo"           # 免费默认，或 tavily / exa / firecrawl

# 沙箱配置
sandbox:
  provider: "LocalSandboxProvider"   # 本地开发
  # provider: "AioSandboxProvider"   # Docker/K8s 生产

# Skills 配置
skills:
  directory: "./skills"

# 上下文压缩
summarization:
  enabled: true
  model: "default"
  threshold: 0.8                 # token 使用超过 80% 时压缩

# 记忆系统
memory:
  enabled: true
  model: "default"
  max_facts: 50
  max_context_tokens: 2000

# 子 Agent 配置
subagents:
  timeout_seconds: 900           # 15 分钟
  max_concurrent: 3

# 数据库
database:
  type: "sqlite"                 # 或 postgres
  path: ".deer-flow/db.sqlite"

# IM 渠道（可选）
channels:
  telegram:
    enabled: true
    token: "${TELEGRAM_BOT_TOKEN}"
  slack:
    enabled: false
  feishu:
    enabled: false
    app_id: "${FEISHU_APP_ID}"
```

## Sandbox 模式选择指南

| 场景 | 推荐模式 | 配置 |
|------|----------|------|
| 本地调试 | Local | `LocalSandboxProvider`（默认不启用 bash）|
| 单机生产 | Docker | `AioSandboxProvider`，每次任务独立容器 |
| 多用户生产 | K8s | `AioSandboxProvider` + `provisioner_url`，Pod 级隔离 |

## 安全注意事项

DeerFlow 具备系统命令执行、文件读写等高权限能力：

**默认安全措施（内置）：**
- 仅绑定 `127.0.0.1`（不暴露公网）
- 虚拟路径系统防目录穿越
- 工具调用审计日志（`SandboxAuditMiddleware`）
- 可选 GuardrailMiddleware（工具调用授权）

**公网部署必须额外配置：**

```nginx
# nginx.conf - 添加 basic auth
location / {
    auth_basic "DeerFlow";
    auth_basic_user_file /etc/nginx/.htpasswd;
    proxy_pass http://frontend:3000;
}
```

或使用 JWT/OAuth2 前置代理：
```bash
# 推荐使用 oauth2-proxy 或 Cloudflare Access
```

**网络隔离建议：**
- 专用 VLAN / 私有网络
- 沙箱容器限制出站网络（仅允许白名单域名）
- 定期审计 `SandboxAuditMiddleware` 日志

## 配置 IM 渠道

以飞书为例：

```yaml
# config.yaml
channels:
  feishu:
    enabled: true
    app_id: "${FEISHU_APP_ID}"
    app_secret: "${FEISHU_APP_SECRET}"
    verification_token: "${FEISHU_VERIFICATION_TOKEN}"
    assistant_id: "default"    # 路由到哪个 Agent
```

```bash
# 启动包含 IM 渠道的 Gateway
make dev
# 或
uvicorn app.gateway.app:create_app --factory --host 0.0.0.0 --port 8001
```

然后在飞书开发者控制台配置 Event 订阅 URL：`https://your-domain/api/channels/feishu`
