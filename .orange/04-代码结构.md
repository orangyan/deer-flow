# 04 代码结构

## 顶级目录

```
deer-flow/
├── README.md / README_zh.md          多语言项目说明
├── config.example.yaml               完整配置模板（~1000 行）
├── extensions_config.example.json    MCP + Skills 配置模板
├── Makefile                          根级命令入口（dev/docker/setup 等）
├── docker/                           Docker 部署文件
│   └── provisioner/                  K8s sandbox provisioner 服务
├── scripts/                          setup / serve / docker / deploy 脚本
├── skills/                           Skills 目录
│   ├── public/                       内置公开 Skills（~14 个）
│   └── custom/                       用户自定义 Skills（gitignored）
├── backend/                          Python 后端
└── frontend/                         Next.js 前端
```

## 关键文件说明

| 文件 | 说明 | 重要性 |
|------|------|--------|
| `backend/packages/harness/deerflow/agents/lead_agent/agent.py` | `make_lead_agent()` — Agent 的组装入口，连接 LangGraph + Middleware + Tools | ★★★★★ |
| `backend/packages/harness/deerflow/agents/lead_agent/prompt.py` | `apply_prompt_template()` — 系统提示构建，700+ 行 | ★★★★★ |
| `backend/packages/harness/deerflow/agents/thread_state.py` | `ThreadState` — LangGraph 状态 schema 定义 | ★★★★★ |
| `backend/packages/harness/deerflow/subagents/executor.py` | `SubagentExecutor` — 677 行，线程池子 Agent 引擎 | ★★★★☆ |
| `backend/app/gateway/app.py` | FastAPI 应用工厂，RunManager 初始化 | ★★★★☆ |
| `config.example.yaml` | 完整配置模板，所有功能的配置说明 | ★★★★☆ |
| `frontend/src/core/threads/useThreadStream.ts` | 前端 SSE 流处理核心 Hook | ★★★★☆ |

## 包结构与依赖关系

```
harness（核心包，可独立发布）
  ↑ 被
app（应用层，Gateway + Channels）
  ↑ 被（但 CI 验证单向性）
tests（测试层）

harness 中的 client.py 提供进程内访问，
避免 test 层对 app 层的循环依赖
```

## 配置文件体系

| 文件 | 用途 | 备注 |
|------|------|------|
| `config.yaml` | 主配置（LLM/沙箱/记忆/IM渠道...）| 从 `config.example.yaml` 复制 |
| `extensions_config.json` | MCP + Skills 运行时配置 | 可通过 API/WebUI 修改 |
| `.env` | API Keys（可选，也可放 config.yaml）| gitignored |
