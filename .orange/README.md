## 项目一句话

**DeerFlow** 是字节跳动开源的 Super Agent Harness（超级 Agent 运行时），基于 LangGraph，具备中间件驱动架构、沙箱执行、Skills 系统、长期记忆和 IM 渠道接入能力。
